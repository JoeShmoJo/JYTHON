This folder contains scripts that are used in CAVI, ResSim modeling, and for post-processing.
Folder descriptions:
alt_config: Contains config files that are used by the ResSim model to instruct scripted rules/state variables what to do.
esp_download: CAVI scripts to download ESP data
ExternalModules: .jar files with Java classes that are used by CAVI/ResSim scripts
externalRules: .py files that are read in and used as scripted rules by the ResSim model.
externalSVs: .py files that are read in and used as state variables by the ResSim model.
NWDJyLib: A Jython library of commonly used functions across NWD. Useful to put code here that is to be used by multiple state variables or scripted rules
Plots_Jython: Jython scripts to produce plots
RealtimeData: Scripts to scrape data for use in real-time ops
RuleList: This folder is not used as input to ResSim or CAVI. Files in here can be exported from ResSim to include all pertinent data about rules in the model.
Utilities: Everything else. Mix of Python/Jython scripts
Willamette: Exports of all scripted rules and state variables from the model. Generated by running Utilities/Save_Scripts.py from within ResSim
