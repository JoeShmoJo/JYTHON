# Willamette ResSim / RTS workflow

The source watershed is `NWP_Willamette_Master_2026_11_10_Multithread`.

Open its `WORKFLOW_README.html` or `scripts/START-HERE.html` for the offline guide.
Start with Initial setup, then the Operator SOP and Workflow buttons. Supporting pages explain configuration, archived forecasts, augmentation, plots, and Model Check.

The watershed includes model definitions and workflow scripts. HEC applications, the desktop Python environment, external inputs, and local saved results belong to the operating installation.

For ResSim script development, see the [JavaDocs API index](RESSIM_API_INDEX.md).

See the [POR workflow handoff](POR_WORKFLOW_HANDOFF.md) for current entry points and operating notes.
