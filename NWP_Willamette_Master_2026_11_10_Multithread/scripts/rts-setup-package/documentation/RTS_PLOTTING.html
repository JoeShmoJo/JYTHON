Plotting saved results

Use Plot Results in RTS or Archive / Plot Results in standalone. Save completed results under a descriptive name and select one or two saved runs for plots. The workflow discovers member IDs from computed results; entering the archive's year span again is unnecessary.

Historical ensemble bands summarize historical members. Synthetic members are shown separately: 3000, 3001, and 3002 are percentile traces; 3003 is OSI when computed. Missing or uncomputed members cannot be supplied by the plotter.

The rule curve is solid black. Median lines are dashed. Comparison plots retain their run colors. Individual traces and references can be toggled using the legend. Reference lines such as minimum-flow requirements and rule curves describe different constraints; use the legend labels to identify them.

Generated HTML plots work locally in a browser. Open Last Plots reopens existing output. To see a plotting-code update, regenerate plots from the saved results; reopening old HTML does not change it.

See saved standalone results for archive selection and RTS reference for file locations.
