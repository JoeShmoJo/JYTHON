Workflow buttons

Follow the Operator SOP for the normal sequence. Compute runs in ResSim or RTS after the workflow loads inputs or settings.

Standalone ResSim

ControlUse it for
Simulation, alternative, Simulation typeSelect the actual target and Ensemble or Single POR.
Baseline ConfigurationEdit operating rules and job settings, save named configurations, and apply a configuration to the selected alternative. Save stores a reusable set; Apply activates it for the next compute.
Extract ensemble inputsDownload the live RFC inputs and supporting data for the selected simulation.
Check archive dates / membersInspect historical archive coverage against standalone job settings before extraction.
Extract archived ensemble inputsLoad historical RFC inputs using the standalone archive settings and selected simulation dates.
Augmentation Configuration (standalone)Select an archived unaugmented baseline, edit/save/open the two-step settings, and calculate/load release requirements before a manual augmented compute.
Archive / Plot ResultsSave a completed baseline or augmented result, then plot selected saved runs.
Model CheckCheck the selected POR output or exactly one ensemble member. Produces a report without starting compute.

Single POR uses the study's existing inputs. The ensemble-extraction controls are disabled in that mode. See POR and Model Check.

ControlUse it for
Refresh forecast metadataRefresh the displayed target after selecting another forecast or run.
Use this displayed forecast after closing it in RTSRetain the displayed target while closing the forecast to release DSS file access.
Initial Extract (live RFC)Download and load the currently published forecast and supporting inputs.

Plot ResultsAccept completed results, choose saved baseline/augmented runs, and plot one or two runs. Members are discovered from computed outputs.
Open Last PlotsReopen existing generated plots. Regenerate plots to incorporate plotting-code changes.

Inside Augmentation Configuration

Open Configuration loads a reusable set. Save Configuration saves it. Process and Load Releases calculates requirements and loads them into the forecast DSS. That button is disabled when baseline coverage does not include a usable conservation season (starting by March 30 and extending through April 1). The season list comes from baseline output coverage.

Short forecast days is the number of days of member-specific inflows used before switching to the saved historical median remaining-runoff estimate. Supporting-reservoir selections and limits control allocation. See augmentation calculation.

Understanding results

Model Check explains reports and coverage. Plotting explains historical bands, synthetic members, and reference lines. Baseline configuration explains applied snapshots and initialization receipts.
