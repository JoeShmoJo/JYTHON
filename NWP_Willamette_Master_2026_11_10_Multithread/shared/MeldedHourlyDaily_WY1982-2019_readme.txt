This takes the high quality hourly data from the Willamette Flow Frequency (HourlyInflowsToResSim.dss from Task 1.12)
and combines it with the
daily average values from the EIS (interpolated to hourly) to produce a DSS file of inputs
that allows the ResSim model to be run continuously in 3-hour timestep from 1981-2019.
These inputs produce good results both for flood events and conservation season.
